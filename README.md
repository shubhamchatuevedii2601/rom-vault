# ROM Vault

A premium ROM download portal demo for the Redmi Note 11T 5G and POCO M4 Pro, built as a responsive React + Vite website with a Liquid Glass aesthetic.

## Included

- Premium glassmorphism UI and dark/light theme toggle
- Homepage with search and featured device cards
- Device-specific pages: `/redmi-note-11t-5g` and `/poco-m4-pro`
- ROM catalog with categories, filters, and download details
- Download page with checksum copy, mirror links, and warning notices
- Demo data clearly marked as sample content
- Responsive layout and accessible controls

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Notes

- Download links are example links only and not hosted from this project.
- The demo is designed to be easy to connect to a CMS or database later.
